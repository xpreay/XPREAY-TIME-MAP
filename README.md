# ICT Time Map

Interaktywna mapa godzin sesyjnych, killzone, ICT macros, CME FX futures oraz relacji czasu NY / Polska / London / Tokyo.

## GitHub Pages

Plik `index.html` jest gotowy do publikacji przez GitHub Pages.

Najprostszy workflow:

1. Utworz repozytorium na GitHubie.
2. Wgraj zawartosc tego folderu do glownego katalogu repozytorium.
3. Wejdz w `Settings -> Pages`.
4. Wybierz `Deploy from a branch`.
5. Ustaw branch `main` i folder `/root`.
6. Zapisz ustawienia.

Po chwili strona bedzie dostepna pod adresem GitHub Pages repozytorium.
